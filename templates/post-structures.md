# Five post structures

Every post in `posts/` uses one of these. They are deliberately short — LinkedIn truncates around 200 characters, so the first two lines do all the work.

---

## 1. Tide Shift
*Reframes what everyone thinks the question is.*

```
[The old question, stated plainly.]

That question is closed. The new question is: [X].

That is not a philosophical shift. It is an operational one.

[Why the shift changes what teams must do — 2 short lines.]

[3–5 bullet list of the consequences.]

[The line that lands: often "none of this is new. That is the point."]

[Question back to the reader.]
```
Use for: trend posts, positioning, the opening and closing of a series.

---

## 2. Mechanism
*Teaches how one thing actually works. The workhorse.*

```
[Claim that sounds wrong for one second, then obviously right.]

The mechanism: [name the pattern — confused deputy, broken access control, supply chain].

[2–3 lines explaining it without jargon.]

The pattern that holds up:
— [control]
— [control]
— [control]
— [control]

[One question to ask at your next review.]
```
Use for: the technical core of the series. Credibility comes from naming the mechanism, not the vendor.

---

## 3. Myth / Fact
*Corrects one widespread, specific mistake.*

```
[Myth, stated as most people state it.]

That is [wrong / half-right], and the difference matters.

[What is actually true — 2 lines.]

[Why the myth persists — 1 line, generous, not sneering.]

[What to do instead.]
```
Use sparingly. One per six posts. Never name a company.

---

## 4. Postmortem Shape
*Opens on the scene of a failure. Highest engagement, easiest to get wrong.*

```
Here is the call your team is not ready for.

"[The quote. Present tense. Uncomfortable.]"

Most estates cannot [do the thing that call demands].

[Why — the gap, in 2 lines.]

What to start capturing today:
— [item] × 5–6

[The lesson, stated once, without drama.]
```
**Rule:** never fictionalise a real incident, never imply it happened to you if it didn't. A hypothetical framed as hypothetical still lands.

---

## 5. Education / Stack
*Explains how several things relate. Highest saves, lowest comments.*

```
[People keep asking X. It is the wrong question.]

**[Thing A]** — [one-line job it does]. It defines *what you must do*.
**[Thing B]** — [one-line job]. It defines *how you run it*.
**[Thing C]** — [one-line job]. It defines *what engineers do on a Tuesday*.

[The one-sentence relationship between them.]

[Which one is missing for you?]
```
Use for: regulation, frameworks, standards, anything people conflate.

---

## Length discipline

| Element | Target |
|---|---|
| Whole post | 130–160 words |
| First line | Under 12 words, complete thought |
| Longest sentence | Under 25 words |
| Bullets | 4–6, one line each |
| Closing question | 1, optional but usually yes |

If a post exceeds 180 words it is two posts. Split it.
