## Where to get defensible numbers

This kit ships no statistics. Where a figure would strengthen a post, pull a current one from a named annual report and cite the report and year in the post itself:

- **Verizon Data Breach Investigations Report (DBIR)** — incident and breach patterns
- **IBM Cost of a Data Breach Report** — breach economics
- **Stanford HAI AI Index Report** — adoption, capability and investment trends
- **ENISA Threat Landscape** — European threat data
- **UK DSIT Cyber Security Breaches Survey** — UK organisational data

**Best of all: your own estate.** "In our environment, non-human identities outnumber humans four to one" is more persuasive than any vendor average, and you can defend it in the comments.

## Verification discipline

1. Open the source. Today. Not a summary of it, not a screenshot in someone else's post.
2. Quote the figure with its year and the report name.
3. If a claim only exists in secondary coverage, cut it.
4. If a framework has been revised since this file was written, the revision wins.

*Links verified as of September 2026. Standards get revised — re-check before citing a clause number.*
